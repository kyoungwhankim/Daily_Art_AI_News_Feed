# UI·UX 디자이너 (ui) — 수십년차 직무 분석가 도메인 지식

## 1. 코어 직무 철학 및 실무 파이프라인 병목 (고정 코어)
- **본질적 역할**: 게임·인터랙티브 미디어의 UI·UX 디자이너는 예쁜 장식 프레임을 그리는 사람이 아니라, **복잡한 시스템 상태와 데이터를 플레이어가 0.1초 만에 오해 없이 읽고 조작할 수 있도록 정보 위계(Information Hierarchy), 시인성(Legibility), 일관된 디자인 시스템(Design System)을 설계하는 인터랙션 아키텍트**다.
- **실무 파이프라인 핵심 병목**:
  1. **벡터 패스 수정 가능성과 나인슬라이스(SVG/Vector & 9-Slice Scalability)**: 인게임 HUD, 버튼, 아이콘은 다양한 해상도와 다국어 텍스트 길이에 맞춰 늘어나고 줄어들어야 한다. 픽셀이 뭉개진 통짜 비트맵 이미지는 스케일링과 상태 변화(Normal/Hover/Pressed/Disabled) 대응이 불가능하다.
  2. **배경 위 시인성과 정보 전달 명확성(Contrast & Readability)**: 화려한 인게임 전투 화면이나 밝고 어두운 배경 위에서도 체력바, 쿨타임, 상태 이상 아이콘의 실루엣이 즉각 구별되어야 한다. 맥락 없는 디테일 과잉은 오히려 가독성을 파괴한다.
  3. **컴포넌트 토큰화 및 엔진 UI 프레임워크 연동(Figma to UMG/UGUI)**: 개별 시안 한 장이 아니라 컬러·타이포그래피·간격 규칙이 시스템화되어 엔진(Unreal UMG, Unity UGUI/UI Toolkit)의 데이터 바인딩 구조와 어긋남 없이 맞물려야 한다.
- **비평 렌즈 (Hype vs Reality)**:
  - AI가 생성한 화려한 게임 UI 목업(Mockup) 대다수는 **읽을 수 없는 가짜 텍스트, 불균일한 여백, 베지어 노드가 수천 개로 깨진 쓸모없는 벡터, 그리고 일관성 없는 아이콘 굵기**를 안고 있다. 실제 프로덕션에서 중요한 것은 '한 장의 시안 생성'이 아니라 **클린한 SVG 패스 제어력, 디자인 시스템 일관성, 그리고 맥락에 맞는 정확한 시각 소통**이다.

## 2. AI 실무 활용 플레이북 (매주 통합·정제)
- **검증된 실무 투입 구간**:
  - **연속 픽셀 보존 + 네이티브 RGBA 기반 상태별 아이콘·프레임 추출**: 바이트댄스 `Seedream 5.5`(100회 연속 수정 시 비수정 픽셀 보존, 네이티브 RGBA 투명 출력, 오타율 0.4%)를 활용해 중심 심벌 픽셀은 고정한 채 버튼·아이콘의 상태(Normal/Hover/Pressed/Disabled) 및 등급별 발광 테두리만 투명 PNG로 일관되게 분리 생성한다.
  - **어도비 로컬 MCP·빌더 및 SVG 벡터 연동 아틀라스 자동화**: 어도비 MAX 2026에서 공개된 포토샵·일러스트레이터 `로컬 MCP`와 파이어플라이 `빌더(Builder)`, `Ideogram Vector`를 결합해 외부 에이전트로 투명 UI 에셋의 4배수 그리드 여백 정렬, 나인슬라이스(9-Slice) 가이드 설정, SVG 베지어 노드 정리를 자동화한다.
  - **다국어 텍스트 확장 스트레스 테스트 및 모션 UI 프리비즈**: 오픈AI `Images 2.6`의 루프 GIF 생성으로 마이크로 인터랙션 타이밍 가이드를 만들고, 에이전트 스크립트로 한국어 대비 2.5배 길이의 영문·독일어 문자열을 UI 컴포넌트에 자동 주입해 레이아웃 깨짐을 조기 검증한다.
- **수작업·베테랑 통제가 필수인 한계 구간**:
  - 인게임 HUD 정보 위계 설계, 제작 초기 단계부터의 게임패드(D-pad/스틱) 포커스 이동 궤적 설계, 외부 데스크톱 AI 오버레이(`e차원` 등)와의 화면 모서리 간섭 방지 및 색약·명도 대비 접근성 검증.
  - 동적 텍스트와 이미지 레이어의 완전 분리, 프로젝트 전체를 관통하는 디자인 토큰·타이포그래피 거버넌스.

## 3. 최신 기술·업계 트렌드 지형도 (매주 통합·정제)
- **어도비의 로컬 MCP·프로토타이핑('빌더') 공세와 네이티브 RGBA 에셋 생성의 결합**: 2026-11-13 주간 어도비는 MAX 2026에서 피그마에 맞서는 파이어플라이 내 프로토타이핑 도구 `빌더(Builder)` 비공개 베타와 함께 포토샵·일러스트레이터를 클로드·챗GPT 등 외부 LLM이 직접 제어하는 `로컬 MCP`를 전면 도입했다. 동시에 바이트댄스가 100회 연속 편집 일관성과 네이티브 투명 배경(RGBA)·0.4% 저오타율을 갖춘 `Seedream 5.5`를 공개하며, UI 아이콘·컴포넌트의 상태 변주 생성부터 레이아웃 슬라이싱까지 에이전트로 연결하는 워크플로가 성숙했다.
- **데스크톱 화면 인식 AI 컴패니언의 확산과 글로벌 패드·다국어 UX 필수화**: 텐센트가 게임 화면을 실시간 비전으로 분석해 전술을 조언하는 데스크톱 AI 컴패니언 `e차원(Eciyuan)`을 출시하며 화면 모서리 점유와 HUD 시인성 설계의 중요성이 더욱 커졌다. 또한 요시다 슈헤이 전 소니 인디 대표가 글로벌 진출의 핵심 전제로 초기 시연 단계부터의 다국어 지원과 게임패드 컨트롤러 완벽 대응을 강조한 것처럼, 생성 속도를 넘어선 다국어 가변 레이아웃과 비마우스 조작 동선 설계가 UI·UX 디자이너의 핵심 경쟁력으로 자리 잡았다.
