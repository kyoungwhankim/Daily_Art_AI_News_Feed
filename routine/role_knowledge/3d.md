# 3D 아티스트 (3d) — 수십년차 직무 분석가 도메인 지식

## 1. 코어 직무 철학 및 실무 파이프라인 병목 (고정 코어)
- **본질적 역할**: 3D 아티스트의 가치는 단순히 '그럴듯한 덩어리(Mesh)'를 빚어내는 데 있지 않다. 게임 엔진이나 렌더 파이프라인 안에서 조명·변형·충돌·성능 예산을 모두 견뎌내는 **구조적 완결성(Production-ready Geometry & PBR Surface)**을 설계하는 것이다.
- **실무 파이프라인 핵심 병목**:
  1. **토폴로지·엣지 플로우(Edge Flow)**: 스컬프팅이나 생성 모델이 만든 비정형 삼각/사각 메시는 관절이 굽혀질 때 찌그러지고, 서브디비전이나 LOD(Level of Detail) 생성 시 실루엣이 무너진다.
  2. **UV 심(Seam)과 텍셀 밀도(Texel Density)**: 자동 언래핑이 아무리 발전해도 하드서페이스 경계선, 노멀 맵 베이킹 아티팩트, 라이트맵 블리딩을 막는 전략적 심 배치와 텍셀 밀도 통일은 숙련자의 판단을 요구한다.
  3. **PBR 채널 정합성**: 단일 알베도(베이크된 조명 포함)가 아니라 디퓨즈·러프니스·메탈릭·노멀·오클루전이 물리 기반 라이팅에서 어떤 각도와 시간대에서도 일관되게 반응해야 한다.
  4. **규격 및 계층 구조(Hierarchy & Pivot)**: 스케일 단위, 월드 원점 피벗, 파츠 분리(모듈러 조립·파괴·장착 가능한 서브메시 분리)가 어긋나면 리거·애니메이터·레벨 아티스트 단계에서 막대한 재작업 비용이 발생한다.
- **비평 렌즈 (Hype vs Reality)**:
  - "이미지 한 장으로 10초 만에 3D 모델 생성" 같은 데모는 늘 **리토폴로지·UV·디라이팅(De-lighting)·파츠 분할 공수**를 숨긴다. 처음부터 클린하게 모델링하는 시간보다, 엉킨 AI 생성 메시를 고쳐 쓰는 시간이 더 오래 걸리는 '수선 역전(Repair Inversion)' 현상을 날카롭게 짚어야 한다.

## 2. AI 실무 활용 플레이북 (매주 통합·정제)
- **검증된 실무 투입 구간**:
  - **초기 블록아웃·원경 프랍 및 상용 REST API 자동화**: 주인공과 상호작용하지 않고 변형이 없는 정적 소품, 바위·잔해·원경 건축물은 Image-to-3D(Hunyuan3D V3.1, Tripo P2.0/H3.1, Meshy REST API 등)로 빠르게 베이스 메시를 뽑아 그레이박스 검증 속도를 3~5배 높인다.
  - **소규모 자체 에셋 기반 오픈 모델 LoRA 미세조정**: 허깅페이스 `TRELLIS.2` LoRA 파이프라인처럼 거대 가중치 전체 대신 골격·부피를 잡는 `Sparse Structure DiT`와 표면 세부 요철을 빚는 `Shape Flow DiT`에만 경량 어댑터를 삽입해, 스튜디오 고유 프랍·장비 에셋 100~200개로 로컬 도커에서 학습시키면 범용 모델 특유의 조형 뭉개짐 없이 하이폴리 스컬프팅 소스를 확보할 수 있다.
  - **로컬 AI 리토폴로지·UV 및 표준 토폴로지 래핑**: CozyBlanket Pro처럼 100% 로컬 오프라인에서 에지 루프와 극점(Pole)을 직관적으로 제어하고 GPU 가속 UV 언랩·UDIM·베이킹까지 처리하는 도구나, Blender `MetaWrap`·Reallusion `CC Wrap`(CC 5.2)처럼 비정형 AI/스컬프팅 메시를 표준 액터 토폴로지(MetaHuman, CC3+/CC5 HD)로 감싸 자동 리깅·스킨 웨이트로 넘기는 파이프라인이 '수선 역전'을 막는 핵심 해법이다.
  - **DCC 내부 반복 공정 및 절차적 노드 연동**: Blender, Houdini(Houdini MCP + OpenUSD), Cinema 4D, Maya, Substance 등 기존 DCC 툴 내부에서 노드·버텍스 단위로 즉시 편집 가능한 에셋 생성·UV 패킹·디라이팅(De-lighting)을 결합하는 하이브리드 워크플로우가 가장 타율이 높다.
- **수작업·베테랑 통제가 필수인 한계 구간**:
  - 히어로 캐릭터·무기·차량처럼 카메라가 클로즈업되거나 리깅·파츠 교체가 일어나는 에셋의 최종 로우폴리 토폴로지, 관절 변형 구간 극점 통제, 하드서페이스 베벨(Bevel) 컨트롤, 정밀 노멀 베이킹.
  - 상용 3D 생성 API 임포트 시 알베도 그림자 제거(De-lighting), PBR 채널 분리, 월드 피벗 정렬, 텍셀 밀도 통일 검수 및 LoRA 학습용 기준 에셋(100~200개)의 정밀 제작.

## 3. 최신 기술·업계 트렌드 지형도 (매주 통합·정제)
- **범용 생성에서 '스튜디오 맞춤형 미세조정(3D LoRA) + B2B API 연동'으로 분화**: 2026-11-13 주간 허깅페이스가 공개한 `TRELLIS.2` LoRA 미세조정 가이드(`Sparse Structure DiT`·`Shape Flow DiT` 타깃 학습, 100~200개 에셋 활용)는 소규모 데이터셋으로 스튜디오 고유의 밑창·요철 디테일과 조형 스타일을 고정하는 실용적 해법을 제시했다. 동시에 Meshy 등 상용 플랫폼은 지스타 2026 B2B관을 통해 언리얼 엔진 연동 및 대규모 에셋 자동화용 REST API를 앞세워 엔터프라이즈 파이프라인 진입을 확대하고 있다.
- **원클릭 생성에서 '리토폴로지·표준 래핑 규격 편입'으로 중심 이동**: 단일 이미지에서 헤어 카드·스프링 본을 동시 생성하는 `HairDeck`, 메타휴먼 표준 토폴로지로 래핑하는 `MetaWrap`, PC용 로컬 AI 리토폴로지·UV 툴 `CozyBlanket Pro`, 외부 AI/DCC 메시를 CC3+/CC5 HD 규격으로 변환·자동 리깅하는 `Character Creator 5.2`(`CC Wrap`)까지 비정형 생성 메시를 엔진·애니메이션 규격으로 수선·편입하는 파이프라인 도구가 성숙하고 있다.
- **에셋 데이터 주권과 로컬 오프라인 구동 선호**: 미공개 프로젝트 에셋의 클라우드 유출 우려에 대응해 로컬 도커 기반의 `TRELLIS.2` LoRA 학습이나 오프라인 구동 리토폴로지 툴처럼 외부 전송 없이 내부 GPU/인프라에서 동작하는 아키텍처가 상용 스튜디오 도입의 필수 요건으로 자리 잡았다.
